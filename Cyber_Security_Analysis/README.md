#Cybersecurity Incident Analysis Dashboard

## Project Overview
An interactive Power BI dashboard developed to analyze cybersecurity incidents, identify security threats, monitor incident trends, and understand their impact.

## Tools & Technologies
- MySQL
- Microsoft Power BI
- Power Query
- DAX

## Dashboard Features
- Cybersecurity incident overview and KPIs
- Incident analysis by type and severity
- Monthly incident trends
- Department and country-wise analysis
- Root cause and affected system analysis
- Incident resolution and financial loss analysis

## Project Objectives
- Identify common cybersecurity threats.
- Analyze incident severity and trends.
- Understand affected systems and root causes.
- Monitor incident resolution.
- Generate meaningful insights through data visualization.

## Skills Demonstrated
SQL | Data Cleaning | Data Analysis | Power BI | DAX | Dashboard Development
